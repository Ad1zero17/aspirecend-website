# Aspirecend Website

Statische Website der Agentur [Aspirecend](https://www.aspirecend.com) – Meta Ads für Fashion- & E-Commerce-Brands.

- Erste Seite: `/wachstum-ads` (deutsche Ads-Landingpage, Redesign der Webflow-Version)
- Kein Build-Step: reines HTML/CSS. Alles, was online geht, liegt in `public/` (Stylesheet in `public/assets/style.css`)
- Lokale Vorschau: `python3 -m http.server` im Ordner `public/`, dann http://localhost:8000/wachstum-ads/
- Kontext & Arbeitsregeln für Claude Code: siehe [`CLAUDE.md`](CLAUDE.md)
